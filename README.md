# Dogus M. Altintas — personal research website

Static academic website published with GitHub Pages at https://altintas-d.github.io/altintas-dm/.

## Pages

- Home: `index.html`
- Research: `research.html`
- Publications: `publications.html`
- About / academic CV: `about.html`
- Contact: `contact.html`

Preview locally with `python3 -m http.server 8765`, then open http://127.0.0.1:8765/.

`assets/` contains styles, conceptual schematics and sharing artwork. `cv/Altintas_Academic_CV_2026.pdf` is the current academic CV. Existing publication PDFs and the previous CV URL are retained for link compatibility.

Canonical URLs, Person/ProfilePage metadata and `sitemap.xml` support discovery. Google Search Console submission and indexing are managed separately. `robots.txt` inside this project subdirectory is not the host-level robots policy.

The existing GA4 measurement ID is retained and loads only on the production hostname and path; localhost previews are excluded.
